INSTALL SAFELY
1. Copy the existing repository to a backup location first.
2. Open the folder inside this ZIP; copy its contents into the GitHub Desktop repository root, MERGE folders and REPLACE matching files.
3. Do not delete your local .git folder. This archive does not contain .git.
4. Examine the GitHub Desktop change list before committing. Verify no unexpected deletions.
5. Commit and Push origin; wait for GitHub Pages to publish.
6. Test: HQ reception/key; city; bridge/tower; ground elevator; 01 admin; floors 02-06; lobby kiosks; arcade; mobile controls.

SECURITY: No server-side infrastructure exists on a static GitHub Pages site. Never store real staff passwords or secrets in this repository.
