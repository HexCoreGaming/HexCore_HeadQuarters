HEXCORE CITY // ZIP 1 OF 4 // WORLD REPLACEMENT

WHAT WAS REPLACED
- The previous cityBuildings, cityPlaza, plazaExtras creation and update calls were removed from index.html. Their original source files are retained as unused reference material.
- The original publicCity building facades were removed, and the old tower's primitive exterior was removed. Existing publicCity interiors, directory, information, receptionist, support-draft functionality and tower elevator remain intact.
- world/remadeWorld.js now provides the new exterior environment, grand corporate spire, four themed featured-game destinations, additional public buildings, pedestrian roads, skyline, bridges, garden details and procedural decorative design.
- Tower remains corporate headquarters; standalone game/commercial destinations are reachable in the public city.

WHAT IS NOT DONE IN ZIP 1
- This is a substantial original procedural visual rebuild, NOT a cinematic AAA environment. Detailed externally modeled GLB assets, high-resolution surface textures, animated character models and bespoke interior redesign are for subsequent releases.
- GitHub Pages cannot provide private secure employee logins, payment processing or live ticket submission without a separate service.

INSTALL
Extract. Copy CONTENTS of this directory into your GitHub Desktop repository root next to index.html. Merge/replace matching files; do NOT delete your other project files. Review for deletions, commit and push. Reload the deployed website.
